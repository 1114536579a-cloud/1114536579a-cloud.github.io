常见问题

你可能想先问清楚

两套获客系统我怎么选？

看你客户在哪：客户在国外社媒（Threads）用 LH 全链任务系统；客户在小红书用 小红书私信 AI 获客。两套是独立程序，装错版本用不了对方的平台。都想要也可以分别下载，授权各算各的。

拿到程序后怎么开始用？

下载后双击运行，程序会显示本机机器码；把机器码发给我们，我们签发一张绑定这台电脑的授权码，粘贴即可使用。桌面版内置《使用说明》，客户端的「官方网站」按钮也能随时打开本页。

需要什么样的电脑？会不会很吃配置？

Windows 10 / 11 即可，免安装、体积小（Threads 版约 870 KB，小红书完整包约 26 MB）。程序本身不吃配置；AI 判断用的是你自己配置的模型 API（如 DeepSeek），按用量计费。

用我自己的模型 API 吗？数据会不会外泄？

用你自己的 API Key，密钥只在你本机加密保存、不写入日志、不上传。台账、词库、日志也全部存在本机程序目录。只有送审的帖子/私信内容会发给你自己配置的模型服务商。

会不会被平台风控？

程序内置多重保护：帖子级永久去重、多账号错峰上线、每小时回复上限、验证码 / 风控 / 登录失效时立即停止该账号，且默认是「只出草稿、人工确认后再发」。我们建议先用低频跑稳再逐步放量。
