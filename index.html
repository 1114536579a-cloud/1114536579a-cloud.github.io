常见问题

你可能想先问清楚

AI 部署需要什么样的电脑？

取决于模型大小：7B~8B 级别，8GB 显存普通显卡就能流畅跑；更大模型用云端 API 或服务器方案。我们会先评估你的硬件，再给性价比最高的路径。

数据会不会被上传到外面？

可以完全本地化：模型、知识库、业务数据都留在你自己的电脑或内网服务器。只有你主动选择云端大模型 API 时，提问内容才会发给对应服务商。

AI 工作流和"直接用现成平台"有什么区别？

平台只是工具，真正决定效果的是流程设计：什么时候触发、怎么判断、异常怎么办、结果给谁。我们负责把流程设计到能长期稳定运行，并接进你现有系统。

网站多久能上线？

单页落地页 2~3 天，多页企业站 5~10 天，含设计、开发、上线部署。想更快也可先用模板站当天上线，再逐步替换成定制设计。

定制程序的版权和授权怎么算？

按项目约定：可以只买使用权（我们维护），也可以买断源码自己运营。拿去做商业软件分发，我们还能做机器码绑定、到期控制、远程停用与自动更新一整套授权体系。

预算有限，能做点什么？

推荐从小处切入：先解决一个最耗人力的环节（自动采集 / 报表 / 回复），几千元级工具就能每天省几小时。跑出效果再逐步扩展。
