LH 全链任务系统

一套把「在 Threads 上找俄语区客户」全流程自动化的 Windows 桌面系统： 多账号拟人采集 → 本地初筛 → 模型多票审核 → 自动回复 / 草稿 → 互动跟进 → 客户台账 → 云端授权与远程管控。 不依赖浏览器扩展，也不依赖任何第三方桌面程序，采集与回复引擎全部内置，已稳定迭代 20+ 个版本。

⚙

账号矩阵 · 独立登录态

最多 3 个 Threads 号并行：每个号独立控制端口、独立 Edge / Chrome 资料目录、独立登录态；A / B / C 错峰上线，互不串号、互不抢登录。

⌁

采集速度三档 · 可按账号单独设

慢 / 标准 / 快换的是整套浏览器行为——滚动步长、滚动间隔、每页滚动上限、页内停留、审核并发一起换。运行中改档位下一轮就生效，不用重启任务。

◈

模型门禁：关思考 + 3 票表决

同一条帖子连问 3 次取多数，避免单次调用的随机性把真实线索判掉；「多数跳过但有一票可回复」的边缘样本会自动复判一次。

✎

自动回复 / 草稿双模式

默认只写草稿、由你人工确认后再发；取消勾选才全自动。两种模式都保留每小时上限与异常停号保护，结果全程记台账。

💬

互动跟进：回评 / 私信再捞一遍

评论之后有人回评或私信，程序会判断内容里有没有真实意图，命中就生成自然话术引导对方看主页资料里的联系方式；只在侧栏出现新消息提示时才点进去看，不频繁刷新。

◎

API 当大脑：关键词自进化

模型不只判帖，还负责策略层——按真实产出新增 / 淘汰 / 加权关键词，每轮输出中文复盘报告；所有改动必须过词形、额度、淘汰节奏等 6 道安全护栏。

⏱

每个账号各自计时

设置「跑 40 分钟、休 20 分钟」时，A / B / C 各自跑满 40 分钟再各自休息 20 分钟；不会出现 B、C 延时启动后「刚开跑任务就快结束了」。

▣

客户台账 + 作者端管控

每条动作都落盘成台账（data\activity.jsonl）；配套作者端可看客户名单、在线状态、授权签发与远程停用 / 恢复，一屏管理。

⚡

云端策略 + 自动更新

核心策略与提示词云端热更新，不用重新发版；客户端启动自动检查更新，侧栏也有「⟳ 检查更新」按钮，可自动下载替换重启。

🛡

软件保护（防破解 / 防分析）

编译机锁 + 出厂水印 + 混淆签名 + 运行时反分析检测；核心授权逻辑放云端，词库与公钥不再以明文存在客户端里。

📘

内置《使用说明》

说明书直接内嵌在程序里，首次运行自动释放到程序目录，点侧栏「07 使用说明」随时打开；换电脑、换人接手都不用另外找文档。

日志全程可查

logs\launcher.log 把每页采集、每轮审核的票型与结论、每次发送结果都记下来；一条线索为什么跳过、为什么没发出去，照日志一分钟能定位。

常见问题

你可能想先问清楚

AI 部署需要什么样的电脑？

取决于模型大小：7B~8B 级别，8GB 显存普通显卡就能流畅跑；更大模型用云端 API 或服务器方案。我们会先评估你的硬件，再给性价比最高的路径。

数据会不会被上传到外面？

可以完全本地化：模型、知识库、业务数据都留在你自己的电脑或内网服务器。只有你主动选择云端大模型 API 时，提问内容才会发给对应服务商。

AI 工作流和"直接用现成平台"有什么区别？

平台只是工具，真正决定效果的是流程设计：什么时候触发、怎么判断、异常怎么办、结果给谁。我们负责把流程设计到能长期稳定运行，并接进你现有系统。

网站多久能上线？

单页落地页 2~3 天，多页企业站 5~10 天，含设计、开发、上线部署。想更快也可先用模板站当天上线，再逐步替换成定制设计。

定制程序的版权和授权怎么算？

按项目约定：可以只买使用权（我们维护），也可以买断源码自己运营。拿去做商业软件分发，我们还能做机器码绑定、到期控制、远程停用与自动更新一整套授权体系。

预算有限，能做点什么？

推荐从小处切入：先解决一个最耗人力的环节（自动采集 / 报表 / 回复），几千元级工具就能每天省几小时。跑出效果再逐步扩展。
